# MBTI 진로 탐색 프로그램

고등학생이 자신의 MBTI 유형을 선택하고, 해당 성향을 참고하여 관심 있게 탐색할 수 있는 직업 3가지를 확인하는 웹 프로그램입니다.

> MBTI는 진로를 결정하는 기준이 아니라, 자신의 흥미와 강점을 탐색하기 위한 참고 자료입니다.

---

## 1. 프로젝트 소개

이 프로그램은 MBTI 16가지 유형별로 직업 3가지를 추천합니다.  
학생들은 추천 결과를 바탕으로 직업의 특징, 관련 학과, 필요한 역량 등을 추가로 조사할 수 있습니다.

### 주요 기능

- MBTI 16가지 유형 버튼 제공
- 선택한 MBTI 유형에 맞는 직업 3가지 추천
- 직업별 설명과 관련 이미지 제공
- 반응형 웹 디자인 적용
- 별도의 라이브러리나 설치 과정 없이 실행 가능
- 모바일, 태블릿, PC 환경에서 사용 가능

---

## 3. 실행 방법

### 방법 1: 브라우저에서 바로 실행하기

1. 프로젝트 폴더를 만듭니다.
2. 제공된 전체 코드를 `index.html` 파일로 저장합니다.
3. `index.html` 파일을 더블 클릭합니다.
4. 웹 브라우저에서 프로그램이 실행됩니다.

### 방법 2: VS Code에서 실행하기

1. Visual Studio Code를 실행합니다.
2. `index.html` 파일을 엽니다.
3. 브라우저 미리보기 기능 또는 Live Server 확장 프로그램을 사용합니다.
4. 화면에서 MBTI 버튼을 선택합니다.

## 5. 사용 방법
화면에 표시된 MBTI 16가지 유형 중 자신의 유형을 선택합니다.
선택한 유형에 어울릴 수 있는 직업 3가지가 표시됩니다.
각 카드에서 직업 이름과 간단한 설명을 확인합니다.
추천 직업 중 관심 있는 직업을 골라 추가로 탐색합니다.
예를 들어 INTJ를 선택하면 다음과 같은 직업이 표시됩니다.

소프트웨어 개발자
데이터 분석가
연구원


--


## 6. 진로 탐색 질문
추천 결과를 본 뒤 다음 질문을 생각해 보면 더 의미 있는 진로 탐색이 가능합니다.

이 직업에서는 실제로 어떤 일을 할까?
이 직업과 관련된 고등학교 과목은 무엇일까?
어떤 대학교 학과와 연결될 수 있을까?
이 직업에 필요한 능력이나 태도는 무엇일까?
내가 좋아하는 활동이나 잘하는 과목과 연결되는 부분은 있을까?
추천 직업 외에 관심 있는 다른 직업은 무엇일까?
